<objective>
## Phase Goal

**As a** developer maintaining FinAlly, **I want to** run backend, frontend and end-to-end suites
that exercise the whole trading loop, **so that** I can change any layer and know within minutes
whether watch, trade, chat and portfolio still work together.

This plan covers TEST-04's **portfolio display calculations**. The backend owns every financial
number (`compute_portfolio_view()` rounds to the cent); the frontend's job is to display those
values faithfully and to perform only a few sanctioned client-side derivations — the header's live
total (already proven in 06-02), a watchlist row's change since page open, and the heatmap's
colour scale. This plan proves the positions table displays server values without recomputing
them, and pins the formatting and colour-scale arithmetic at their exact thresholds.

Purpose: display regressions — a sign lost on zero, a P&L silently recomputed from a stale price, a
heatmap that stops saturating at 10% — look plausible on screen and are easy to miss by eye.

Output: four test files.
</objective>
