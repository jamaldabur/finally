<objective>
**As a** user of FinAlly, **I want to** start the entire application with a single command, **so that**
I can trade and chat without installing Python, Node, or a database — and still find my portfolio
exactly where I left it after a restart.

This plan is the tracer for that story: one `docker build`, one `docker run`, and the whole app —
frontend and every API route — answers on port 8000 with its SQLite file living in the repo's own
`db/` directory.

Purpose: Phases 1-4 built a complete application that currently only runs from two terminals and a
hand-built frontend export. DEPLOY-01 and DEPLOY-02 turn it into one artifact. The tracer proves the
full vertical path — Node build stage -> Python runtime stage -> FastAPI serving static + API ->
bind-mounted SQLite -> data surviving a container replacement — before any script polish is layered
on top in Plan 05-02.

Output: a committed `Dockerfile` and `.dockerignore`, one guarded `StaticFiles` mount in
`backend/app/main.py` with regression tests, and the committed `.env.example` that DEPLOY-04 asks
for and that Plan 05-02's scripts point users at.
</objective>

| repo working tree → Docker build context | Everything not excluded by `.dockerignore` is uploaded to the daemon and can land in an image layer, including secrets and user data |

| browser → container port 8000 | The only network surface; serves both untrusted-path static requests and every API route |
