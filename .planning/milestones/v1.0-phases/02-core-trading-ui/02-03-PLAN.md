## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FastAPI → Browser (`GET /api/portfolio`) | Backend-generated monetary values and ticker symbols cross into the DOM. |
| Browser internal (price store → header total) | The one place in the phase where a displayed monetary figure is computed client-side rather than read from the API. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Tampering | `Header.tsx` `useLiveTotalValue` | medium | mitigate | The client-recomputed total is display-only and is never placed in a request body; every mutation still sends only `{ticker, side, quantity}` to `POST /api/portfolio/trade`, so a tampered client total cannot reach persisted state. Scope is fixed at `cash_balance + Σ qty × price`; no other figure is derived client-side |
| T-02-10 | Spoofing | Header presenting a dollar balance beside live-looking prices | medium | mitigate | A visible `SIMULATED` marker sits beside the portfolio total so a viewer cannot reasonably read the terminal as a funded brokerage account |
| T-02-11 | Repudiation | Connection dot showing green while the stream is dead | low | mitigate | Status is derived from real `onopen`/`onerror` transitions plus a `readyState !== EventSource.OPEN` check inside the grace timer, rather than from "a component mounted"; a stale-green dot would misreport data freshness to someone about to trade on it |
| T-02-12 | Tampering | `PositionsRow.tsx` rendering backend monetary strings and ticker symbols | low | mitigate | All rendered as JSX text children; the repository-wide check from Plan 02-01 keeps any raw-HTML rendering path out of `frontend/` |
| T-02-13 | Denial of Service | 5-second `GET /api/portfolio` interval in `portfolioStore.tsx` | low | accept | Single-user, same-host, in-process SQLite read; one request every 5s is negligible against the 0.5s SSE broadcast the same backend already sustains, and an in-flight refresh is not double-fired |

No package-manager installs occur in this plan, so no package-legitimacy gate applies.
</threat_model>
