<objective>
Stand up the `frontend/` Next.js project and prove the whole Phase 2 architecture with one real
end-to-end slice: a live AAPL price streaming from the running FastAPI backend into the browser,
and a real market order placed from the browser that changes cash and positions in SQLite.

Purpose: every later plan in this phase (watchlist, positions table, header) hangs off the shared
price store, the API client, the portfolio context, and the dark-theme tokens this plan creates.
Proving them end-to-end now means an architectural dead-end costs one plan, not four. Per D-10 the
project is Next.js App Router + TypeScript + Tailwind CSS with `output: 'export'` from day one; per
D-11 the code is idiomatic TypeScript/React (camelCase values, PascalCase components), not a mirror
of the backend's Python conventions; per D-12 components live in feature folders with shared
primitives under `components/ui/`.

Output: a running, buildable `frontend/` project; `lib/types.ts`, `lib/format.ts`, `lib/api.ts`,
`lib/priceStore.tsx`, `lib/portfolioStore.tsx`; the D-08 page shell; a complete trade bar (UI-07);
the PLAN.md §2 palette as Tailwind v4 `@theme` tokens (UI-10); and a six-line dev-only CORS
middleware on the existing FastAPI app so `next dev` on :3000 can reach the backend on :8000.
</objective>
